# Five-Hour Limit, Get Lost!（原生 Windows 轻量版）

解压发布包后，在解压目录运行 `install.ps1` 创建桌面快捷方式，也可以双击同目录的 `start-five-hour-limit-get-lost.bat`。

监管任务时有两种模式：

- 自动检测：只读取所选原会话的日志；必须同时找到明确的用量限额失败和对应五小时重置时间，普通额度遥测不会触发续跑。
- 手动五小时循环：用时间选择器选择一个恢复的“时:分”，不需要填写年月日；界面会预览连续的 5 小时计划（例如 20:32、01:32、06:32、11:32、16:32、21:32），程序会在每个周期重新尝试仍未完成的监控任务，并在恢复后按“缓冲分钟”再启动任务。

时间依据是 Windows 本机系统时间，不联网取时间。建议缓冲分钟保留默认的 2 分钟。

续跑始终使用原会话 UUID 和历史，不另开对话。若 Codex 返回“already has an active writer”，任务会显示“等待原会话释放”，按 15、30、60 秒间隔重试。若桌面端或 IDE 仍持有原会话，请在原宿主中有序释放；调度器不会结束不明归属的 Codex 进程。右键任务可以查看错误详情和本地日志；结果不确定时，核对原会话后再使用“核对后重试原会话”。

每个任务可以使用自己的“续跑指令”：顶部输入框用于新任务，选中已有任务会回填它保存的指令；也可以在任务列表右键选择“编辑续跑指令”，修改后立即保存。留空时使用默认指令。

任务队列和续跑日志保存在 `%LOCALAPPDATA%\CodexQueueCN\`。旧队列会自动迁移；重启时未确认结果的任务会进入核对状态，避免重复提交。程序不会绕过五小时或每周限制，也不会自动打开危险权限模式。
